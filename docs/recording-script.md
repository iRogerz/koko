# 錄影腳本（AC-17）

目標時長 **3～4 分鐘**。涵蓋三種情境 + 四項加分。

原則：**不要只是點一點給人看畫面會動，要把「做對了」演出來。**
這題的陷阱都藏在資料處理，畫面上有對應的可見證據，下面每一段都標了要指哪裡。

---

## 0. 錄影前準備

| 項目 | 建議 |
|---|---|
| 機型 | 用新機型錄（畫面漂亮）。但**先在 iPhone SE (3rd gen) 跑一次**——設計稿基準是 375×667，空狀態在矮螢幕上最容易擠 |
| 網路 | 要能連 `dimanyen.github.io`，三個情境都打真實 API |
| 錄製 | Simulator 選單 **File ▸ Record Screen**，結束後存成 `.mp4` |
| 開始前 | 從情境選擇頁開始，不要錄到 Xcode 編譯畫面 |
| 節奏 | 每個畫面停 2～3 秒再操作，捲動放慢——快速滑過等於沒展示 |

先跑一次完整流程再開錄，避免中途卡住重錄。

---

## 1. 情境選擇頁（約 10 秒）

停在選單上，讓三個情境的標題與副標看得清楚。副標已經寫明每個情境打哪些 API，
這一格本身就是在說明「情境切換是怎麼設計的」。

---

## 2. 情境二「只有好友列表」（約 60 秒）— **最重要的一段**

先進這個，因為本題最主要的陷阱在這裡。

**操作**

1. 點「只有好友列表」
2. 等清單載入，**停 3 秒讓整頁看得清楚**
3. 慢慢往下捲一次，再捲回頂端

**要指出的三件事**（用滑鼠停留或放慢捲動帶過）

| 看哪裡 | 證明了什麼 |
|---|---|
| **畫面上沒有任何邀請卡片** | `updateDate` 有做正規化。F1 用 `20190801`、F2 用 `2019/08/02`，直接字串比較會讓 fid 001 取到錯的那筆而變成邀請卡片，這裡就會多出一張卡 |
| **兩個「梁立璇」都在** | 去重用 `fid` 不是 `name`（004 / 005 同名不同 fid） |
| **有星星的排在最上面**，其餘維持原順序 | `isTop` 置頂排序，且排序是穩定的 |

另外可一併帶到：「翁勳儀」右側是灰色**邀請中**標籤（`status == 2`），
其他人是 `⋯`（`status == 1`）——兩者互斥。

> 這段是整支影片最有價值的部分。如果只錄得完一段，錄這段。

---

## 3. 加分：下拉更新（約 15 秒）

接著上一段，**留在情境二**。

1. 從清單頂端往下拉，放開
2. 粉紅色轉圈出現 → 資料重新載入 → 轉圈收起

**要點**：下拉時**畫面不會閃回骨架**，清單原地更新。這是刻意的——
下拉本身已經有轉圈動畫，再閃一次骨架很突兀。

---

## 4. 加分：搜尋框上推（約 30 秒）

一樣留在情境二。

1. 點搜尋框 → **畫面上推**，搜尋框貼到頂部功能列下方
2. 輸入「梁」→ 清單即時篩選到兩個「梁立璇」
3. **停 2 秒**（同時證明搜尋是子字串比對、且兩筆同名的都留著）
4. 按「取消」→ 關鍵字清空、清單還原、畫面捲回原位

**要點**：篩選是本地的，**沒有重新打 API**。

---

## 5. 情境三「好友列表含邀請」（約 45 秒）

回上一頁（**從螢幕左緣往右滑**——設計稿沒有返回鍵，是刻意的），選「好友列表含邀請」。

1. 載入後停 2 秒：上方有**邀請卡片**，第二張錯位露出底邊暗示可展開
2. 注意「好友」tab 右邊出現 **badge 數字**，等於邀請卡片數
3. **點卡片區 → 展開**，所有卡片完整列出（加分項目：展開收合動畫）
4. **再點一次 → 收合**
5. 展開狀態下按其中一張的 **✓**，該筆邀請消失、badge 數字跟著減少

**要點**：✓／✕ 是純前端行為，**沒有對應 API，不會發任何請求**——
這是需求本身就沒給的，不是漏做。

---

## 6. 情境一「無好友」（約 20 秒）

回上一頁，選「無好友」。

1. 空狀態畫面：插圖 + 「就從加好友開始吧：）」+ 綠色漸層按鈕 + 底部設定 KOKO ID 連結
2. 注意 header 顯示「**設定 KOKO ID**」+ 粉紅小圓點（這個情境的使用者沒有 kokoid）
3. 「聊天」tab **沒有 badge**（一個好友都沒有的新用戶不會有 99+ 則聊天）

**要點**：空狀態判定用的是「合併後好友**總數**為 0」，不是「一般好友數為 0」——
只有邀請沒有一般好友時仍然是好友列表，不是空狀態。

---

## 7. 分頁切換（約 15 秒）

在任一情境下：

1. 點「聊天」→ 只有 segment 以下變空白，header 與 segment 留著
2. 點回「好友」→ 內容還原
3. 點底部「錢錢」/「記帳」/「設定」→ 整頁空白（那是另一個分頁）
4. 點中央 **KO** → 內容空白，KO 字轉粉紅
5. 點回「朋友」

**要點**：非「朋友」分頁的內容是需求指定的空白畫面，不是還沒做。

---

## 8. Unit Test（約 20 秒）

切到 Xcode，跑一次完整測試，讓 **Test navigator 全綠**入鏡。
可以停在 `FriendMergerTests` 或 `UpdateDateTests` 上，展開看測試名稱——
名稱本身就在說明測了什麼。

（第四項加分就是 Unit Test，這段不能省。）

## 容易 NG 的地方

- **捲太快**。清單只有六筆，慢慢捲，讓兩個「梁立璇」看得到。
- **忘了錄 Unit Test**。它是四項加分之一，只講不錄等於沒做。
- **在情境二找邀請卡片**。那裡本來就沒有——「沒有」才是正確的，別以為是 bug。
- **用返回鍵**。設計稿沒有 navigation bar，返回是從左緣往右滑。
- 錄到一半切出 Simulator，畫面會停格。
